# raw/

Jogue aqui qualquer arquivo para a IA analisar: croquis, fotos, desenhos (DWG, DXF, STEP), PDFs e planilhas.

- Nada desta pasta vai para o git: só este README é versionado (`.gitignore`: `raw/*`).
- Pode ter dado de cliente da fábrica: não envie para a nuvem sem o acordo do Nonno e da fábrica (ver `docs/PLAN.md`).
- Depois de analisado, o que vira dado de teste vai para `local/` (também fora do git).
